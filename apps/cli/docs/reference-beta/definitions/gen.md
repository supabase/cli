Generate typed definitions from your database schema, plus JWT signing keys and Bearer tokens for local development.

Use `gen types` to get type safety and autocompletion in your application code. Use `gen signing-key` and `gen bearer-jwt` to create the keys and tokens that the local stack and the Data API accept.
