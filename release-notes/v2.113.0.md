## Supabase CLI v2.113.0 — 2026-08-08

This release improves error reporting and continues the TypeScript migration. The CLI now properly surfaces `serve` staging errors and handles timestamps with timezone offsets.

### Bug fixes
- `supabase serve` now displays staging errors instead of suppressing them (#6113)
- **API calls now accept timestamps with timezone offsets** (#6117)

### TypeScript port progress
- **Now served by the TypeScript shell:** `db reset`, `gen bearer-jwt`, shell completion. Behavior matches the Go CLI. (#6026, #6064, #6083)

Plus 1 internal dependency update.
