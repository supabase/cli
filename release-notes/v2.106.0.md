## Supabase CLI v2.106.0 — 2026-06-11

This release improves reliability for function deployments and declarative workflows, adds Git branch linking to `branches create`, and continues porting core commands to TypeScript.

### ⚠️ Breaking changes
- **`auto_expose_new_tables` now defaults to false** — New projects won't automatically expose all tables through the API; you'll need to explicitly configure which tables to expose. If you're upgrading an existing project, check your `config.toml`. (#5524)

### Highlights
- **Function deployments now retry on rate-limit errors** — Transient rate limits won't immediately fail your deployment; the CLI will retry automatically. (#5534)
- **Declarative workflows now automatically set up platform baseline** — No need to manually provision the baseline before running `declarative apply`. (#5515, #5521)

### New features
- **Link Git branches when creating Supabase branches** — Use `supabase branches create --git-branch <branch>` to specify which Git branch to associate. (#5250)
- **JSON output mode for coding agents** — Agent commands now default to JSON output, enabling easier programmatic integration. (#5532)

### Improvements
- `db pull` with the pg-delta diff engine now skips unnecessary `pg_dump` runs, speeding up schema pulls. (#5255)

### Bug fixes
- Custom hostname validation records and SSO SAML IDs no longer crash the CLI when missing. (#5485, #5543)
- Vector storage now fails gracefully — local vector storage is skipped if unavailable, and you're warned when remote buckets are offline instead of silent failures. (#5508, #5535)
- Channel selection (via `--experimental` or `SUPABASE_CHANNEL`) is now preserved when delegating to the Go proxy. (#5546)

### TypeScript port progress
- **Now served by the TypeScript shell:** `bootstrap`, `config push`, `functions delete`, `functions download`, `gen signing-key`, `gen types`, `services`. Behavior remains unchanged from the Go CLI. (#5470, #5489, #5527, #5501, #5514, #5468)
