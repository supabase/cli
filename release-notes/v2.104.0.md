## Supabase CLI v2.104.0 — 2026-06-03

Mostly bug fixes and TypeScript ports. Key improvements for automation: `-o machine` output is clean for CI, JSON status returns all fields, and `supabase start` handles corrupted telemetry gracefully.

### Bug fixes
- **`status -o json` returns complete output** — excluding postgrest no longer hides the `api_url` field; critical for CI scripts using JSON status. (#5335)
- **`-o machine` output no longer corrupted by spinner** — spinner is suppressed in machine-readable format, fixing CI and automation integration. (#5410)
- **`supabase start` recovers from corrupted telemetry** — malformed `telemetry.json` is regenerated instead of crashing with a parse error. (#5405)

### TypeScript port progress
- **Now served by the TypeScript shell:** `encryption get-root-key`, `encryption update-root-key`, `postgres-config get`, `postgres-config update`, `postgres-config delete`. Behavior matches the Go CLI. (#5409, #5404)

Plus 3 internal improvements and dependency updates.
