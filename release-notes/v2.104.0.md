## Supabase CLI v2.104.0 — 2026-06-03

This release fixes machine-readable output handling and continues the TypeScript migration of core commands.

### Bug fixes
- **Machine-readable output (`-o machine`) no longer includes spinner characters** — progress animations are now suppressed when using machine-readable format, keeping output clean for parsing. (#5410)

### TypeScript port progress
- **Now served by the TypeScript shell:** encryption commands and Postgres configuration. Behavior matches the Go CLI. (#5409, #5404)

Plus N internal improvements and dependency updates.
