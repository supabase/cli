## Supabase CLI v2.104.0 — 2026-06-03

This release improves telemetry reliability, fixes machine output formatting, and continues the TypeScript port.

### Bug fixes
- CLI no longer crashes when telemetry JSON fails to parse. (#5405)
- `-o machine` format output no longer includes spinner animation on stdout, fixing machine-readable output. (#5410)
- Telemetry configuration and routing corrected. (#5411, #5412)

### TypeScript port progress
- **Now served by the TypeScript shell:** encryption commands, postgres config. Behavior matches the Go CLI. (#5409, #5404)

Plus 1 internal dependency update.
