## Supabase CLI v2.104.0 — 2026-06-03

Continues the TypeScript migration with fixes for telemetry handling and output formatting.

### Bug fixes
- `supabase` no longer outputs spinner characters when using `-o machine` format (#5410)
- Fixed crashes when the CLI failed to parse telemetry data (#5405)
- Corrected telemetry routing to production and schema-decode configuration (#5411, #5412)

### TypeScript port progress
- **Now served by the TypeScript shell:** `encryption`, `db postgres`. Behavior matches the Go CLI. (#5409, #5404)
