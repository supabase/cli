## Supabase CLI v2.119.0 — 2026-09-30

This release delivers stability improvements for local development with 30+ fixes focused on Docker container management, networking, and connection handling. Key fixes address Docker Desktop compatibility on macOS and Windows, session persistence, and request routing. OrioleDB configuration graduates from experimental to stable.

### Highlights

- **Storage uploads fixed on Docker Desktop for macOS** — Resumable uploads and S3 endpoints now work through the gateway. (#6921)
- **Stack connection details visible on start** — Database URL, MCP endpoint, and other connection info show immediately after launch for easier debugging. (#6894)
- **OrioleDB configuration is now stable** — Move from `experimental_oriole` to standard `oriole` config. (#6828)

### New features

- **Type generation languages from registry** — `gen types` automatically picks up new language targets as Supabase adds them. (#6822)
- **Studio MCP server at `/mcp`** — Serve Studio's Model Context Protocol server for AI agent and third-party tool integration. (#6898)
- **Edge function testing improvements** — New testing entrypoint and Promise-based API. (#6841)

### Improvements

- Docker preferred over Podman for automatic runtime selection. (#6859)
- Containers named by project and service for visibility. (#6867, #6870)
- Studio stays active 5 minutes after last request. (#6866)
- Function `deno.json` files loaded as Deno configuration. (#6907)

### Bug fixes

- Storage and network connectivity on Docker Desktop (macOS and Windows). (#6921, #6887)
- Stacks clean up when Docker is unavailable. (#6825)
- Migra session settings persist through database reconnects. (#6884)
- Local functions read request bodies before responding. (#6830)
- Escape sequences in quoted strings no longer split incorrectly. (#6906)
- Yes/no prompts reject unrecognized answers. (#6910)
- Database socket connections require authentication. (#6833)
- Postgres containers stop cleanly. (#6834)
- Upstream connections reused across proxied requests. (#6925)
- Image pulls retry on transient registry failures. (#6879)
- Mailpit database isolated per stack. (#6901)
- SMS provider configuration handled when unset. (#6685)
